# Luxe Beauty Studio

Luxe Beauty Studio is a web-based appointment scheduling application developed for my Software Development Capstone project.

## Technologies Used
- PHP
- MySQL
- HTML and CSS
- XAMPP
- InfinityFree

## Features
- Customer registration and login
- Beauty service listings and search
- Appointment booking
- Appointment rescheduling and cancellation
- Customer account management
- Password changes
- Session-based access protection

## Live Website
https://luxebeautystudio.infinityfreeapp.com/index.php

## Database
The application uses a MySQL database to manage customers, services, employees, and appointments. Database credentials are excluded from this public repository.

## Project Purpose
The purpose of this project is to demonstrate web application development, database integration, user authentication, and appointment management.

## Project Summary
Luxe Beauty Studio is a web-based appointment scheduling application created for my Software Development Capstone project. The goal of this project was to develop a functional website that allows customers to view beauty services, create accounts, and manage their appointments online.

The application was developed using PHP, MySQL, HTML, and CSS. I used XAMPP for local development and testing and InfinityFree to host the live website. The MySQL database stores customer information, beauty services, employees, and appointment records.

The main features include customer registration, login, service searching, appointment booking, rescheduling, cancellation, and password management. I also implemented security features such as password hashing, prepared SQL statements, session protection, input validation, and CSRF protection on the registration form.

Throughout the project, I tested the application, corrected errors, and improved its functionality. I also expanded the services table to include 12 records and verified that the application works on the live website.

This project helped me gain practical experience with web development, database management, application security, troubleshooting, and deploying a functional website.
