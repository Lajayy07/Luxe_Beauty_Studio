# Luxe Beauty Studio

Luxe Beauty Studio is a web-based appointment scheduling application developed for my Software Development Capstone project.

## Technologies Used
- PHP
- MySQL
- HTML and CSS
- XAMPP
- InfinityFree

## Features
- Customer registration and login
- Beauty service listings and search
- Appointment booking
- Appointment rescheduling and cancellation
- Customer account management
- Password changes
- Session-based access protection

## Live Website
https://luxebeautystudio.infinityfreeapp.com/index.php

## Database
The application uses a MySQL database to manage customers, services, employees, and appointments. Database credentials are excluded from this public repository.

## Project Purpose
The purpose of this project is to demonstrate web application development, database integration, user authentication, and appointment management.
